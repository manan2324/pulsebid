# Load testing

Phase 12 adds k6 constant-arrival-rate scenarios, Vegeta cross-checks, and
recorded performance evidence. The binding targets and test design are in
[Sections 16–18 and Appendix C of the build plan](../PulseBid%20Build%20Plan.md).

Phase 0 contains directory placeholders only. Postman latency checks will not
substitute for concurrent load or multi-replica overspend tests.
